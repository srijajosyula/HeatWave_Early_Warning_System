# Datasets & Geospatial Data 🗺️📊

This folder stores static and semi-static datasets used across the project:

### Structure
- `zones/`: GeoJSON or Shapefiles representing city wards, districts, and administrative boundaries.
- `historical/`: Historical weather records, heatwave mortality/morbidity reports, and baseline climate averages.
- `vulnerability/`: Demographic vulnerability data (e.g. population density, age distribution, outdoor worker proportion).
